## 🚀 Kurulum (3 dakika):

```bash
cd frontend

# Bağımlılıkları yükle
npm install

# Development server başlat
npm run dev
```

**Tarayıcıda aç:** http://localhost:3000

## 🎨 Özellikler:

✅ **Modern Stack:**
- React 18 + TypeScript
- Vite (lightning fast build)
- Tailwind CSS (beautiful design)
- React Query (smart caching)
- React Router v6 (routing)

✅ **Authentication:**
- Login / Register sayfaları
- JWT token management
- Auto refresh token
- Protected routes

✅ **UI Components:**
- Professional layout with sidebar
- Loading states
- Toast notifications
- Responsive design
